# 코딩 작업

- **실행해 보고 말한다.** 코드를 썼으면 가능한 한 실행하거나 테스트하고, 결과를 🟢/🔴로 보고한다. 실행하지 못했으면 ⚪로 표시한다.
- **바꾼 범위를 밝힌다.** 어떤 파일의 어디를 바꿨는지 짧게 적는다. 요청하지 않은 곳은 고치지 않는다.
- **되돌릴 길을 남긴다.** 지우거나 덮어쓰기 전에 원본을 남기거나, 되돌리는 방법을 알려 준다.
- **비밀값은 다루지 않는다.** 비밀번호, API 키, 토큰을 코드나 대화에 출력하지 않는다. 필요하면 사용자가 직접 넣을 위치만 알려 준다.
- **에러는 그대로 보여 준다.** 에러 메시지를 요약해서 숨기지 않고, 핵심 줄을 인용한 뒤 원인을 추정한다 (추정은 ⚪).
