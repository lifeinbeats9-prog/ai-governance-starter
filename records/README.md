# 기록 (records)

중요한 결정과 결과를 날짜별로 남기는 곳입니다. 두 AI가 같은 기록을 읽기 때문에, 한쪽에서 한 일을 다른 쪽이 이어받을 수 있습니다.

## 언제 남기나

- 방향을 바꾸는 결정 ("A 대신 B로 하자")
- 큰 작업의 결과 (성공이든 실패든)
- 나중에 "그때 왜 그랬지?"가 궁금해질 만한 것

사소한 대화는 남기지 않습니다.

## 어떻게

1. AI가 `TEMPLATE.md` 형식으로 초안을 제안합니다.
2. 사용자가 확인하면 `records/YYYY-MM-DD-짧은-제목.md`로 저장합니다.
3. AI가 직접 저장할 수 없으면 사용자가 GitHub 웹에서 **Add file → Create new file**로 붙여 넣습니다.

기록은 고치지 않고 쌓습니다. 이전 결정이 바뀌면 새 기록을 남기고 이전 기록을 링크합니다.
